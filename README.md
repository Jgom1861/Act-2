## Proceso seguido

1. Creé una cuenta en GitHub.
2. Instalé Git y GitHub Desktop.
3. Creé el repositorio `Act-2` en GitHub.
4. Cloné el repositorio en mi computador.
5. Elaboré un documento de Word por cada capítulo del libro Pro Git y lo exporté a PDF.
6. Para cada capítulo agregué los archivos (`git add`) y los confirmé con un mensaje descriptivo (`git commit`). Usé GitHub Desktop, que ejecuta estos mismos comandos de forma gráfica.
7. Envié los cambios al repositorio remoto en GitHub (`git push`).
8. Documenté el proceso en este archivo README.md.

## Comandos básicos utilizados

- `git clone <url>`: clonar el repositorio remoto.
- `git add .`: agregar los cambios al área de preparación.
- `git commit -m "mensaje"`: confirmar los cambios con un mensaje.
- `git push`: enviar los commits a GitHub.
